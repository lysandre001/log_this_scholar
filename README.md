# Log this scholar BETA - Google Scholar Information Collection Extension

Too many scholars to follow but don't know how to manage them? Use Log this scholar BETA to copy standardized information from Google Scholar researcher profiles with one click, making it easy to manage on any platform. Start building your scholar think tank today!

## Features

- ✅ One-click copy of researcher information (name, affiliation, citations, canonical URL, homepage, research topics)
- ✅ **Custom Tags**: Support for adding custom tags, input with comma separation, automatically converted to pipe separation in output
- ✅ **Memo**: Support for adding memo information, automatic CSV escaping (supports special characters like commas, quotes, etc.)
- ✅ Right-click menu for quick operations
- ✅ Extension popup for viewing and editing information
- ✅ Elegant error handling and status notifications
- ✅ Modern UI design following Apple Design System

## Installation

1. Open Chrome browser and navigate to `chrome://extensions/`
2. Enable "Developer mode" in the top right corner
3. Click "Load unpacked"
4. Select this project directory
5. Extension installed!

## Usage

### Method 1: Right-click Menu
1. Open any Google Scholar researcher profile page (URL format: `https://scholar.google.com/citations?user=...`)
2. Right-click on the page
3. Select "Copy Scholar Info"
4. Information copied to clipboard

### Method 2: Extension Popup (Recommended)
1. Open any Google Scholar researcher profile page
2. Click the extension icon in the browser toolbar
3. Click the "Log this scholar" button to extract information
4. View the extracted information in the popup:
   - View all automatically extracted fields (name, affiliation, citations, etc.)
   - **Add custom tags**: Enter tags in the "Tags" input field, separated by commas (e.g., `tag1, tag2, tag3`), automatically converted to pipe separation in output
   - **Add memo**: Enter any memo information in the "Memo" text area, supports multi-line text and special characters
5. View the complete output format in the "Full Output" area
6. Click the "Copy Full Output" button to copy the complete information to clipboard
